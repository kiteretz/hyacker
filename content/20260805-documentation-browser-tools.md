## 回答

プログラミング言語の仕様やライブラリの API ドキュメントを、インストール済みの言語・フレームワークを横断してすばやく検索・閲覧するには、専用のドキュメントブラウザを使う。代表的なものに `Dash`・`DevDocs`・`Zeal` がある。

## 解説

### Dash

- https://kapeli.com/dash
- Mac の定番ドキュメントブラウザ
- 有料（$29.99）
- WordPress の関数、Bootstrap のコンポーネント、React の API など、幅広い Docset に対応

### DevDocs

- https://devdocs.io/
- ブラウザから利用できる
- オフラインでも利用可能

### Zeal

- https://zealdocs.org/
- Windows / Mac / Linux に対応
- Windows のネイティブアプリで使いたい場合はこれが候補になる
- Qt 製のため、インターフェースはやや古い印象

### 日本語ドキュメントについて

いずれのツールも、標準で表示される仕様書は英語。  
日本語化したい場合は、Docset（ドキュメントのデータセット）を自作する必要がある。
